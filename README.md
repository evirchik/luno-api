### **LUNO API**

**Luno** - это pet-проект, представляющий собой интернет магазин одежды.

**Luno api** - это серверная часть магазина создания на основе NodeJs с использованием NestJS.

## Стек проекта

-   NestJS
-   JWT
-   Swagger
-   Postgresql

Данный стек выбран в связи его обширной поддержки и большой информацией о каждом инстументе. Так же сервер на данных технологиях будет прост для дальнейших **расширений проекта**.

## Как запустить сервер 

Для локального запуска сервера потребуется [Установить](https://www.docker.com/) Docker на свой компьютер. Дальше потребуется выполнить команд находясь в папке проекта: 

`docker compose up --build`

После запуска можно перейти по ссылке `http://localhost:5000/docs` для ознокомления с документацией проекта на swagger.
